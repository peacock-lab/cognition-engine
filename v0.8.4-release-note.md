# Cognition System v0.8.4

v0.8.4 is a preview-only saved session management release for the Cognition System public packages.

## What Changed

1. The primary product entry remains `cognition-console ask --guided`.
2. Successful reviewable source QA runs can be explicitly saved as continuable evidence sessions.
3. Saved sessions can be listed with `cognition-console session list`.
4. Saved sessions can be previewed with `cognition-console session resume-preview --session-id <id>`.
5. Saved sessions can be deleted with `cognition-console session delete --session-id <id> --yes`.
6. The preview path shows safe session state, source scope, resume hints, and runtime visible summary references.
7. Deleted sessions return `session_not_found` instead of continuing to expose stale preview state.
8. The public package baseline continues to depend on `google-adk==2.1.0`.
9. The release workflow baseline is Node24-ready for Trusted Publishing.

## Install

```bash
python -m pip install --upgrade pip
python -m pip install "cognition-system==0.8.4"
```

## Product Entry

```bash
cognition-console ask --guided
```

Guided mode asks for the source URL or evidence path, the question, model choice, external-readonly fetch approval, and controlled model approval.

## Saved Session Preview

```bash
cognition-console session list
cognition-console session resume-preview --session-id <id>
cognition-console session delete --session-id <id> --yes
```

`resume-preview` is preview-only. It does not automatically generate a resumed answer, does not claim long-term memory, and does not expose raw prompts, raw provider responses, secrets, tracebacks, or ADK raw objects.

## ADK Boundary

This release does not open ADK Task API runtime, Workflow Runtime, MCP tools, ArtifactService persistence, durable ADK Session, Memory, Skills, callbacks, or plugins. Task API / A2A Task Runtime and Workflow Runtime remain product architecture axes for future implementation, while this release only exposes safe product-level session preview behavior.

## Safety Boundary

The system does not silently access the network, silently call a model, silently read or save provider keys, expose raw provider responses, or present saved session previews as long-term memory.

## Validation Summary

The release preparation line validates package metadata, public materials, local build artifacts, install-state smoke, preview-only session commands, and Trusted Publishing workflow readiness before any tag, GitHub Release, or PyPI upload is performed.
