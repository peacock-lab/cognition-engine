This file summarizes public release changes for Cognition System.

## v0.7.0

`v0.7.0` is the new public PyPI baseline for Cognition System.

Highlights:

1. Renamed the public aggregate distribution to `cognition-system`.
2. Added a dedicated `cognition-system-cli` package while keeping the `cognition` console command.
3. Published the corrected multi-package baseline for runtime, contracts, schemas, configuration, adapters, observation, agent-facing views, and product gateway candidates.
4. Added packaged default configuration resources and the `cognition config init` entry point.
5. Added controlled CLI task workflow shells for plan, reference review, configuration explanation, run workspace evidence audit, and status summaries.
6. Added candidate-only memory and skills projection helpers without enabling unrestricted runtime memory or skills execution.
7. Tightened public release boundaries so public materials, workflow checks, and package metadata align with the `v0.7.0` baseline.

Compatibility note:

`v0.7.0` starts a new public baseline. Earlier experimental package names are not compatibility targets for this release line.
