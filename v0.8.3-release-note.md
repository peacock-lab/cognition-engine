# Cognition System v0.8.3

v0.8.3 is an ADK 2.1.0 baseline patch release for the Cognition System public packages.

## What Changed

1. The public package baseline now depends on `google-adk==2.1.0`.
2. The primary product entry remains `cognition-console ask --guided`.
3. The reviewable source QA flow was verified on the ADK 2.1.0 source baseline.
4. Machine-readable ask output is available with `cognition-console ask --guided --json`.
5. The v0.8.2 install-state default configuration and Trusted Publishing hard-gate work are carried forward.

## Install

```bash
python -m pip install --upgrade pip
python -m pip install "cognition-system==0.8.3"
```

## Product Entry

```bash
cognition-console ask --guided
```

Guided mode asks for the source URL or evidence path, the question, model choice, external-readonly fetch approval, and controlled model approval.

## Review Boundary

Successful ask runs can expose product-level review refs such as answer run, answer artifact, answer trace, observability summary, and trace inspect refs. These refs are product-level review handles. They are not ADK Task ids, Workflow run ids, durable Session ids, or ArtifactService object ids.

## ADK Boundary

This release does not open ADK Task API runtime, Workflow Runtime, MCP tools, ArtifactService persistence, durable Session, Memory, Skills, callbacks, or plugins. ADK 2.1.0 upstream changes around artifact loading, telemetry, conversation trajectory, MCP tool error handling, and evaluation utilities remain governed baseline facts unless separately productized in later tasks.

## Safety Boundary

The system does not silently access the network, silently call a model, silently read or save provider keys, expose raw provider responses, or present current-process follow-up context as long-term memory.

## Validation Summary

The private task chain completed ADK 2.1.0 release impact review, isolated compatibility smoke, dependency upgrade with controlled regression, and product entry experience validation before this release preparation line.
