# Cognition System v0.8.1 Release Notes

v0.8.1 is the first PyPI-synchronized release for the Cognition System product console and the reviewable material question-answering package.

This release focuses on a product-facing experience: users can install Cognition System, start the product console, provide an external read-only URL or evidence path, explicitly approve the read/model steps, and receive an answer with a reviewable run reference.

## Install

```bash
pip install cognition-system==0.8.1
```

## Start

```bash
cognition-console ask --guided
```

The guided flow asks for:

1. the URL or evidence path to read;
2. the question to answer;
3. the model route, such as local `gemma4` or external `deepseek`;
4. explicit approval for external read-only fetching;
5. explicit approval for controlled model answering.

## What Is New

### Product Console

`cognition-console` is now the recommended product entry for the current release line.

The product console provides a user-facing terminal experience for the reviewable material QA package. It is separate from the lower-level compatibility CLI and is designed around product actions rather than command plumbing.

### Reviewable Material QA

Users can ask questions based on external read-only materials. The system forms a governed answer and exposes an `answer_run_ref` as the primary review handle for the current run.

In JSON mode, users can inspect additional review details such as trace, artifact, observability, and trace-inspect references when available.

### Follow-Up And Answer Transformation

Within the current process, users can continue asking questions around the same governed evidence or transform the previous visible answer, such as:

- summarizing;
- translating;
- formatting;
- rewriting.

These follow-ups are temporary and process-local. They are not long-term memory, durable sessions, or workflow runs.

### Safer Boundaries

The system keeps explicit governance boundaries:

- no silent network access;
- no silent model calls;
- no silent provider key reads or saves;
- no raw provider responses in user output;
- no traceback exposure in normal product output;
- no claim that a temporary follow-up is long-term memory.

If the evidence is too short for a requested long-form output, the system returns a governed explanation instead of fabricating a white paper, roadmap, or unsupported expansion.

## PyPI Packages

v0.8.1 publishes the root package and the related component packages as version `0.8.1`.

The main install target is:

```bash
pip install cognition-system==0.8.1
```

The current dependency graph installs the product console, product gateway, application/runtime assembly, schemas, behavior contracts, observability support, evaluation support, external-readonly support, and compatibility CLI packages required by this release.

## Runtime Baseline

This release keeps the current ADK baseline at:

```text
google-adk==2.0.0
```

It does not enable ADK Task runtime, Workflow Runtime, durable Session, Event stream, ArtifactService, Memory, model-initiated Tools, Skills, callbacks, or plugins by default.

## Known Boundaries

1. `cognition-console ask --guided` is the recommended product entry.
2. `cognition external-readonly ask --guided` remains available as a compatibility and technical entry.
3. Review references in this release are product-level review handles, not durable cross-process objects.
4. Local model usage requires a local model service such as Ollama with the configured model available.
5. External provider usage, such as DeepSeek, requires explicit authorization and provider key setup.
6. This release is available on PyPI and should be installed with the pinned version `0.8.1`.
